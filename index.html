📘 DOKUMENTASI APLIKASI, KEAMANAN & DAFTAR UJI

1. Petunjuk Menjalankan Aplikasi di Browser

Simpan kode sebagai berkas index.html lalu klik dua kali untuk membukanya di Google Chrome atau Microsoft Edge (Desktop maupun perangkat seluler). Tidak memerlukan instalasi server lokal untuk menjalankan prototipe interaktif ini.

2. Pengaturan Kelas & Mode Latihan vs Mode Penilaian

Klik tombol "Pengaturan Guru" di halaman awal. Guru dapat menambahkan nama kelas (misal: X-A, X-B, X-C, X-SIJA) dan memilih antara Mode Latihan (bebas mengulang) atau Mode Penilaian (pelanggaran pindah tab langsung membatalkan sesi, menetapkan skor = 0, dan meminta PIN Guru GURU10 jika murid yang sama ingin mengulang sesi penilaian).

3. Penjelasan Batas Keamanan Browser & Kebutuhan Backend

  • Deteksi Visibilitas & Fokus: Aplikasi menggunakan Page Visibility API (visibilitychange) untuk mendeteksi perpindahan tab/minimalkan jendela secara akurat. Event window.blur hanya dijadikan sinyal peringatan pendamping agar notifikasi sistem sesaat tidak langsung merugikan murid.
  • Keterbatasan Sandboxing Web: Aplikasi web standar di dalam browser tidak dapat secara penuh mengunci sistem operasi, memblokir Alt+Tab, atau menutup tab lain. Untuk ujian berisiko tinggi, sekolah disarankan memadukan aplikasi ini dengan Safe Exam Browser (SEB) atau mode Kiosk pada Chromebook/Windows terkelola.
  • Perlindungan Bank Soal & Skor (Backend): Pencegahan klik kanan dan salin-tempel (copy/cut/paste) pada panel soal hanya menghalangi tindakan kasual. Untuk pelaksanaan penilaian resmi yang tahan manipulasi DevTools/localStorage, gunakan arsitektur Server Backend (Node.js/PHP/Python) yang mengirimkan soal satu per satu menggunakan token sesi, memvalidasi jawaban di sisi server, tanpa menyertakan kunci jawaban di klien.

4. Daftar Pengujian Kualitas (QA Checklist)

  • ✅ Validasi form identitas kosong ditolak sebelum mulai.
  • ✅ 15 Kotak Misi tersebar berurutan hingga Portal Finis.
  • ✅ Setiap kotak misi hanya memunculkan 1 soal unik.
  • ✅ Skor +10 hanya dihitung 1x per soal (anti klik ganda).
  • ✅ Timer 30 detik bebas dari penggandaan interval.
  • ✅ Tombol "Lanjutkan Misi" terkunci sebelum menjawab.
  • ✅ Gerbang finis menolak akses jika misi < 15 selesai.
  • ✅ Pindah tab saat Mode Penilaian mereset skor menjadi 0.
